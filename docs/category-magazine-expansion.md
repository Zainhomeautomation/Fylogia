## Personalization and compatibility

Categories can be followed/unfollowed without automatically following new publications or replacing existing source IDs. Onboarding and My Sources use the same recommendation/interest model, with source-specific new topics. For You continues to require selected sources and interests. New categories are additive metadata for existing saved articles; no database migration or destructive reset. Category navigation, reader return state, the shared page-curl system, offline library, Daily Editions, custom feeds and optional private sync continue using their existing implementations.
