# Regulatory compliance foundation — risk report

Reviewed 1 November 2026. Operator: personal project based in Oman, serving an international audience. This is an engineering risk assessment, not legal clearance. No country/topic restriction is activated. No documented territorial licence or binding restriction has been supplied. Ratings indicate potential impact and unresolved questions, not findings of illegality.

## Architecture verified in code

- Scheduled GitHub ingestion (`scripts/refresh-feeds.mjs`, `feed-content.mjs`, `article-content.mjs`) retrieves public publisher RSS/Atom, not paywalled pages. Full text is restricted to nine configured source policies; item-level exceptions and third-party media exclusions apply. Feed availability alone grants no permission. Unverified custom feeds remain previews. Publisher names, original URLs and applicable full-text credits travel with article bodies.
- Articles/previews and image URLs are committed to **public GitHub** in `public/data/edition.json`. Builds generate public per-source JSON on Cloudflare Pages. Reader presentation does not make these private. Historical Git commits remain accessible. Public repository code licensing does not license publisher materials.
- Browser localStorage stores preferences, saved articles, history/progress; IndexedDB and Cache Storage hold permitted offline articles/images and magazines. Export/import is user controlled. No data migration or deletion is introduced by this foundation. Existing offline copies cannot be retroactively geo-revoked.
- Optional sync uses private Cloudflare D1 profiles, device cookies, hashed credentials, approval-based pairing/recovery and server authorization. Bibliographic metadata, interests, history/progress and settings sync; publisher bodies/images/PDFs do not. It is pseudonymous, not anonymous or end-to-end encrypted. Profiles persist until deletion; device credentials last one year. Pairing/pending recovery proofs last five minutes; recovery keys persist until rotated/deleted. Abuse controls use salted network-derived hashes and bounded expiry cleanup.
- Local News alone requests `/api/location`, reading trusted Cloudflare `request.cf.country`. Two-letter country held only in tab memory, no GPS, city, raw IP response, location history, sync or service-worker API cache. Hosting still processes connection IPs. Manual editorial regions are independent.
- Images, direct/custom feeds, original publisher pages and original PDF relays involve external providers. Optional rss2json conversion discloses the custom-feed URL to that provider. Local summaries do not send article bodies to an external AI service.

Official register entries were searchable; full official page fetches failed (gateway/timeout). The exact operative text and subsequent amendments must be obtained and interpreted by counsel; no article-specific prohibition is asserted here.
- [MTCIT personal-data authority](https://www.mtcit.gov.om/sectors/governance/personal) identifies Law 6/2022, Regulation 34/2024, permit and complaint/breach processes. [MTCIT notice for Royal Decree 68/2026](https://mtcit.gov.om/ar/3/8/75/1481), dated 6 September 2026, confirms amendments concerning scope, exceptions and automated processing. An assessment limited to the original 2022/2024 texts is incomplete. The Ministry-hosted English regulation PDF timed out; no unverified deadline or exemption is treated as established.
- [WIPO Lex: Oman Copyright and Neighboring Rights, 65/2008](https://www.wipo.int/wipolex/en/legislation/details/5832), available text/version record. Review current amendments and exceptions with counsel. News facts are distinct from protected expression and photographs; attribution alone does not grant republication rights.
- [Cloudflare trusted request metadata](https://developers.cloudflare.com/workers/runtime-apis/request/#incomingrequestcfproperties) documents network country. No territorial enforcement is inferred from editorial regional preferences.

This screening does not certify every publisher licence, every jurisdiction, regulator approval or App Store eligibility. A future native release needs separate rights/privacy/platform review.

## Implemented foundation and boundaries

`config/content-distribution.json` contains **zero active rules**. Rules must specify a source, explicit ISO countries, allow/deny mode, legal/licensing reason and public evidence. Approval additionally requires legal-review and owner-approval references plus review dates. Do not commit private legal advice, contracts or personal information. Draft rules never change distribution.

The tested geographic evaluator supports allow/deny territories, unknown-country refusal for applicable approved rules, intersection of multiple rules and expired-review refusal. It is reserved for a future trusted server-side private origin, **not wired to the public reader as misleading enforcement**. It assumes validated configuration.

The actual ingestion/build guard refuses publication if any approved territorial rule is configured: public snapshots cannot safely satisfy it. The guard runs before feed retrieval and before production build/static slicing, including retained cached material and aliases. A failed build does not remove the previously deployed site or public Git history. Before activating a rule, plan existing-content remediation and seek owner approval; never rely on a failed deployment to implement a live block. This foundation deliberately does not activate production restrictions.

## Operating procedure

1. Record an actual legal order or publisher contract, affected source/rights/territories, dates, counsel review, owner approval and remediation obligations. No category or keyword-derived ban.
2. Submit a draft rule and impact report first. Use public evidence plus a non-secret reference to confidential advice; keep advice out of Git.
3. Determine distribution architecture, legacy/public-cache exposure and offline licence compatibility. Public snapshot mode rejects approved rules until an appropriate reviewed alternative exists.
4. Test both allowed/denied and unknown countries, licence expiry, article duplicates, cached copies, user-data preservation and original links. Deploy only the approved design; minimise geo data.
5. Re-review at policy dates and publisher changes; track rights requests privately. Do not claim automatic compliance or retroactive revocation.

No media restrictions, content removals, new location requests, account/DNS changes or user-data deletions were made in this milestone. Privacy notice now also discloses the existing optional feed converter. Operator contact and legal classification remain owner/counsel actions.
